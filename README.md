# キッザニア福岡 館内音響自動化システム

要件定義書: [docs/キッザニア音響自動化システム_要件定義書.md](docs/キッザニア音響自動化システム_要件定義書.md)

Windowsタスクスケジューラーで個別に行っていた館内音楽・ステージ演出の再生を
1つのPythonアプリに統合するツールです。

## できること

- 「通し営業」「2部制営業」など営業モードごとに個別のスケジュールを持ち、
  GUIでその日のモードを選んで運用開始
- モードに関わらず常時有効な共通ジョブ(街時計ダンス音楽など)
- GUIの「スケジュール管理」画面から、時刻・ファイル・音量を
  タブ(共通/モード別/手動追加/ステージショー)ごとに追加・編集・削除
- 上記のプリセット以外に、GUI上で時刻とファイルを自由に指定して
  追加できる「手動追加」枠
- 「ステージショーモード」をONにすると、拡張ディスプレイ(会場側スクリーン)を
  黒画面で待機表示にする。ステージショーのボタンを押すとその画面に動画が流れ、
  終了後も黒画面を保持したままなのでWindowsデスクトップは露出しない
- ステージショー動画(ダンスショー/ファッションショー)をGUIのボタン一つで
  フルスクリーン再生(音声・映像同期)。ファッションショーのように
  MV1/MV2…と複数動画を持つショーは「次のMV ▶」ボタンで手動切り替え
  (自動では次に進まない)
- 「■ 停止」ボタン(またはESCキー)でいつでも再生/待機画面を停止・終了できる
- 再生失敗時もアプリ全体は止まらず、ログに記録

## セットアップ

### 1. VLCメディアプレーヤーのインストール

`python-vlc` は内部でVLC本体を利用します。事前に
[VideoLAN公式サイト](https://www.videolan.org/vlc/) からVLCをインストールしてください。
**Pythonのビット数(通常64bit)とVLCのビット数を揃えてください。**

### 2. Python依存パッケージのインストール

```
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. メディアファイルの配置

`media/` フォルダ配下に音源・動画ファイルを配置します。

```
media/
  bgm/            館内BGM等
  street_clock/   街時計ダンス音楽
  stage_shows/    ステージショー動画(mp4等)
```

### 4. 設定ファイルの編集

- `config/settings.json` … アプリ全体設定
- `config/schedule.json` … 営業モード別スケジュール(`common_jobs`=共通、
  `modes`=モードごとのジョブ、`manual_jobs`=手動追加、`active_mode`=選択中モード)
- `config/stage_shows.json` … ステージショーのボタン一覧(動画・音量)

現時点ではサンプル/プレースホルダーの内容が入っています。実際の時刻・
ファイル名・音量は運用担当者・音響映像スタッフに確認のうえ書き換えてください
(要件定義書「8. 未確定事項」参照)。アプリ起動中でもGUIの「スケジュール管理」
画面から時刻・ファイル・音量をまとめて変更・保存できます。

## 起動方法

```
run.bat
```

または

```
python -m src.kidzania_sound.main
```

起動すると常駐し、以降はスケジュールに沿って自動再生されます。
ステージショーを行う際は、先にGUI上部の「ステージショーモード」をONにしてから
(拡張ディスプレイが黒画面の待機状態になります)、各ショーのボタンで手動再生
してください(**事前に音響映像スタッフが操作盤で「イベント卓」に切り替えて
いることが前提**、本システムはその切替を制御しません)。

終了するにはGUIウィンドウを閉じてください。ログは `logs/kidzania_sound.log` に
記録されます。

## 現状の制約・今後の確認事項

要件定義書の「8. 未確定事項」を参照してください。特に以下は実運用前に
関係者へ確認が必要です。

- 館内BGMのダッキングが完全自動(音声検知)か、明示的な制御が必要か
- 「イベント卓に切替済みか」の確認ステップをGUIに追加するか
- 音源・動画ファイルの命名規則
- 実際のスケジュール一覧
- PCのスリープ/スクリーンセーバー設定(本アプリはSetThreadExecutionStateで
  実行中の自動スリープを抑止していますが、OS側の電源設定も別途確認推奨)
- 映像切替機材(イベント卓)のAPI対応有無
